## Catálogo de atacado Movement

Catálogo para lojistas, com ficha de produto, busca, filtro, carrinho e pedido. Os produtos ficam em JSON e o site é gerado com Node.

- Site: https://benattin.github.io/catalogo-movement/
- Código: https://github.com/Benattin/catalogo-movement

Stack: JavaScript, HTML, CSS e Node.js.
